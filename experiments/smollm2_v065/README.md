# 🧪 Espacio de Pruebas: SmolLM2-v0.6.5-Genomic

Este directorio contiene el organismo genómico **SmolLM2-135M** evolucionado nativamente en Rust mediante el Protocolo GAJE.

## Archivos
- `smollm2-evolved.gaje`: El cerebro digital de 37 MB (2 bits).
- `validate_organism.sh`: Script de validación automatizada.
- `results/`: Salidas de texto generadas por el modelo.

## Ejecución
Para validar el modelo, ejecuta desde la raíz del proyecto:
\`bash
./experiments/smollm2_v065/validate_organism.sh
\`
